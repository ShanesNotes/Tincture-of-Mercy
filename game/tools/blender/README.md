# Blender character pipeline (D4)

`.blend` sources are canon. GLB + sidecars are build artifacts, regenerated by one command.

Schema: [SIDECAR_SCHEMA.md](SIDECAR_SCHEMA.md). Tick law: [frame_data_v0.json](frame_data_v0.json) (verbatim from `design_system/v1_0_threejs_soulslike/TUNING_V0.md` where that table names a move).

## Regenerate

From the repo / worktree root:

```bash
# Optional Meshy front-end (cached; falls back if the API is down)
python3 game/tools/meshy/generate.py --all

# Rebuild blocking rigs + clips from proportions JSON
/home/ark/.local/bin/blender --background --python game/tools/blender/author_blocking.py -- all

# Export hashed GLB + 60Hz sidecars
/home/ark/.local/bin/blender --background --python game/tools/blender/export_character.py -- game/assets/src/wolf.blend game/assets/build
/home/ark/.local/bin/blender --background --python game/tools/blender/export_character.py -- game/assets/src/kalev_blocking.blend game/assets/build

# CI gate
python3 game/tools/blender/check_sidecar.py game/assets/build
```

Meshy downloads (if any) land in `game/assets/src/meshy/<id>/` with `provenance.json`. They are reference meshes only — armatures and clips in `wolf.blend` / `kalev_blocking.blend` are authored here, never Mixamo/CC0.

## Re-proportion Kalev

Edit `game/assets/src/kalev_proportions.json` (`head_body_ratio`, `head_height_m`) and re-run `author_blocking.py -- kalev`. Clips key **bone rotations + root XZ**, not absolute joint locations, so retiming is not required.

## Determinism pins

| Source | Pin |
|---|---|
| Scene | factory empty; metric; 60 fps / `fps_base=1` |
| Mesh | `from_pydata` boxes; one vertex group per part, weight 1.0 — no automatic weights |
| Animation | linear key handles (`FREE`); integer frames 1..N = ticks 0..N-1 |
| GLB | `export_extras=False`, `export_copyright=""`, `export_optimize_animation_size=False`, `export_image_format=NONE`, materials `PLACEHOLDER` |
| GLB post | JSON chunk rewritten: `asset.generator=tincture-export/0`, extras stripped, keys sorted, space-padded; SHA-256 of that byte stream is `glbHash` |
| Sidecar | `sort_keys`, 6-decimal floats |

Remaining nondeterminism: Blender `.blend` internal block order / timestamps (source, not a build input to the sim). Re-export from the committed `.blend` is the GLB/sidecar source of truth. If a Blender point-release changes GLB packing, re-run export and commit the new hash.
