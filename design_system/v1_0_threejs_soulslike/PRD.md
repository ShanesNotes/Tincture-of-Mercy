# v1.0 PRD — Tincture of Mercy, three.js souls-like

Owner directive (Shane, 2026-08-13): resurrect the game; keep the lore; scrap the care mechanics; adventure combat mirroring Elden Ring / Dark Souls with the Tincture as the flask; entirely three.js; art strictly in the illuminated fairy-tale register; council-resolved decisions; no shortcuts. Decisions: `DECISIONS.md`. Gates: `GATES.md`. Tuning: `TUNING_V0.md`. Encounters: `ENCOUNTERS.md`.

## Goal
Ship the Ironwood vertical slice as a browser souls-like in three.js whose combat weight, world feel, and art register pass the measurable gates derived from the Elden Ring bar, on an architecture honest enough to carry all six pilgrimage legs.

The phrase "Elden Ring standard" is discharged by **named reference encounters and measurable thresholds** (GATES.md), not vibes: reference points are the Margit/Tree-Sentinel class of telegraph-and-punish grammar for the Warden, Stormveil-courtyard pack pressure for the wolves, and the Elden Ring flask/death/rest loop for the Tincture/Open Page/Hearth cycle.

## Success criteria (each command-verifiable)
1. **Determinism**: a recorded input script reproduces a full combat encounter tick-for-tick; golden-replay Vitest suite green (same-V8 scope; versioned replays).
2. **Souls combat complete**: stamina (Breath), poise (Steady) with flinch/stagger/knockdown, dodge i-frames, guard/chip/guard-break→riposte, backstab, Attend lock-on, commitment attacks with tracking windows and per-tick frame data, sim-owned hitstop, directional damage — per-mechanic unit tests + the frame-data table IS the implementation (no magic numbers; lint-enforced).
3. **The Tincture is Anna's medicine**: doses prepared for her in the prologue carry forward as the player's flask; Hearth refill; Tincture Wheel crafting (15-item pouch → the five canon variants); Ember with Numbness cost including world-text register degradation → sim tests + playable loop.
4. **Death loop**: the Open Page drops at the death site, one recovery, second-death loss; Hearth rest respawns standard enemies → e2e test.
5. **Ironwood slice playable start-to-boss**: prologue → wolves → shortcuts → Anna gravity encounter (staged, non-combat, canon-locked) → the Warden (two phases, E-7 ceremony) → Birdie coda → Playwright e2e completes it; 60fps perf gate on WebGPU (p95 ≤13.3ms boss scene); WebGL2 fallback functional + register-gated.
6. **Art register**: Art Gate A1–A7 machine rows exit 0; A8–A15 panel rows pass against the four fixed reference plates (GATES.md).
7. **VERIFY-ALL**: `npm --prefix game run verify` = typecheck + lint (incl. sim-purity and sim-time bans) + vitest + Playwright + perf budget + art-gate machine rows, all exit 0, in CI.
8. **Feel Gate**: F-rubric (GATES.md) passes two consecutive rounds on gamepad; golden replays are not a substitute.

## Non-goals
Porting Godot/C# code; care-mechanic substrate; shipping or 1:1-deriving from the scanned plates (style emulation only — "emulate the hand, never copy the page"); multiplayer; legs 2–6 content (architecture must scale; content is Ironwood); mobile; moving platforms/rigidbody puzzles/cloth-sim truth; parry (riposte via guard-break only).

## Requirements

**R1 sim/** — pure fixed-tick 60Hz core: zero three.js imports (arrows-check), seeded RNG, serializable versioned state DTOs, input-script replay, golden replays in CI (same-engine scope), lint bans on wall-clock/random in sim, browser-lifecycle pause semantics, frame-pacing strategy + test.
**R2 Combat** — stamina economy; poise buildup w/ hyperarmor windows; dodge bands by Burden load; guard stability/chip/guard-break→riposte; backstab; Attend + unlocked combat both first-class; movesets (light strings, heavy, charged, running, rolling, jump attack or explicit deferral); tracking windows per attack; hitboxes as analytic swept capsules (3 sub-steps) vs hurtbox capsules with uniform-grid broadphase; static-world queries via `CollisionWorld` (three-mesh-bvh); sim-owned per-actor hitstop; damage types (standard/strike/pierce/slash + Wither); the Turn as buildup meter (margin-narrowing render); committed flask-drink and Ember-use clips in the frame-data table.
**R3 Controller/camera** — deterministic capsule controller (D8 spec, property-tested); sprint/jump/fall damage; third-person camera state machine w/ collision, Attend framing, reverse-Z, FOV 38–48°; input contract (edge-latched tick queue, buffers, no key repeat); gamepad first-class + remapping + deadzones; staged-framing handoffs in no-damage moments only.
**R4 Enemy AI** — perception (sight cones, sound events); utility selection with telegraphs and cooldown weighting; wolf pack roles + attack token (one attacker per 3.5m ring); deterministic nav (baked walk graph, stable tie-breaks, off-mesh links for drop-downs, leash reset, pack-slot contention and crowd-failure handling); Warden boss per ENCOUNTERS.md with punish-window guarantees.
**R5 RPG layer** — attributes Pulse/Breath/Hands/Steady/Spirit/Sight leveled at Hearths by spending Names; Burden equip-load bands gating dodge class; weapon upgrade via pouch materials; charms (Cedar Dog slot 1); armor negation; vocation-path hooks (Apothecary/Hesychasm/Iconographic).
**R6 Tincture system** — dose charges + Hearth refill; the Wheel: pouch combinations → the five variants; Ember (2/slice, non-craftable): full restore + cleanse + surge, cost = permanent Numbness stacks (−8% healing, +25% Turn buildup, one register step of world-text degradation each; partial restore at Hearth); drinking is a committed, punishable, survivable-if-timed action.
**R7 Death/recovery** — the Open Page at the death site (≤0.5m), one recovery, second-death loss; run-state semantics: boss-arena state machine (entry gate, no respawn on victory, reset on death, mid-fight quit-out), enemy respawn on rest, Open Page across save/quit.
**R8 World** — authored Blender-blockout geometry, baked quantized collision BVH (hash in saves); interconnection + shortcuts (≥1 drop-down, ≥1 unlockable gate); Hearths; item pickups with polyphonic lore cards; NPC staging (Anna, Iiro, Birdie); zone streaming with residency/load budgets and bake-slow/load-fast caching; the full Ironwood leg.
**R9 Presentation** — WebGPU/TSL painted register enforcing renderer laws L1–L12 + reverse-Z + quantized depth bands; ink-outline pass; palette-clamped grade; ornamental HUD border with enumerable verdict states (Pulse/Breath/doses/Names count live in the border); menus + item cards (polyphonic, Numbness-aware); water = thin TSL Gerstner layer w/ jewel-tone override + ink crests, flow-map rivers, TSL rain/wetness (sim owns wind/fetch/wetness as numbers — no FFT ocean, no SPH); VFX in-register (ink-bloom impacts, Wither motes, flask glow as emblem light); shader precompile at load (zero first-swing compile stutter); asset streaming + deterministic disposal.
**R10 Audio** — tick-synced audio architecture: sample-accurate impact scheduling from sim events (cue onset at active-minus-N), AudioContext unlock flow, voice limits, ducking, controller rumble + reduced-feedback modes; content: damp-November ambience, weighted combat SFX, Warden theme, Hearth theme, the tag-chime; liturgical restraint; audio carries ~half of impact weight (no screenshake exists).
**R11 Persistence** — versioned save slots + settings; explicit migrate-or-reject on version mismatch; deterministic-safe serialization.
**R12 QA/tooling** — Vitest unit + property tests (controller geometry, sweep tunneling at max angular velocity, stamina/poise invariants); golden replays; Playwright e2e scenario set (frozen per gauntlet round) with input overlay + i-frame debug dumps; perf budgets (sim p95, render CPU/GPU p95, pacing, boot, heap/VRAM, disposal) on both backends; art-gate harness; clip↔frame-data CI gate; **combat workbench**: frame stepping, replay scrubbing, visible capsules, displacement paths, cancel windows, poise/stamina/buffer state, hot-reloaded tuning tables.
**R13 Code quality** — TS strict, no `any`; sim pure and dependency-zero; frame data as data; every system unit-testable headless; animation state machine + cancel graph explicit in data; Blender-only cast animation (Mixamo banned for the cast); style matches repo idiom; surgical diffs.
**R14 Polyphonic text system** — layered folk/Church/State strings for items, NPCs, UI; register selection by speaker and by Numbness level; degradation + Hearth partial-restore rules. Core system (Ember's cost depends on it), not polish.
